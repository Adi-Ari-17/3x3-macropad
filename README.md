# 3×3 Macropad

A simple, open-source 9-key macro pad powered by Seeeduino XIAO RP2040.

## Features
- 3×3 ortholinear key matrix
- QMK firmware with layer support
- USB-C charging & programming
- 3D-printable sandwich case
- Hot-swappable MX switches

## Build Time
Estimated: 30–45 minutes

## Parts Required
See `BOM.csv` for full component list.
